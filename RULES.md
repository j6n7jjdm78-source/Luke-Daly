# Posting rules
- Call-outs are posted BEFORE any result post; mcap at call is logged in calls.csv at post time. Never backdate.
- Every call goes in calls.csv. Winners and losers both appear in the weekly scoreboard.
- Each call-out states position honestly: "I don't hold this" or "I hold this".
- Results posts say "called at X, now Y". Never claim realised PnL unless backed by real wallet transactions.
- Call-outs need owner approval (move file drafts/ -> approved/) before posting.
- Result post triggers at >=2x of mcap_at_call.
- Not financial advice line on every call-out.
